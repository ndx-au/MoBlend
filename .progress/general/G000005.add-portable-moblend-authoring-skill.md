# Add a portable MoBlend production authoring skill

## Summary

Added a standalone skill at the owner's request for harnesses authoring MoBlend productions. It uses ordinary files, CLI execution and image inspection, without harness-specific tools, metadata or installation paths. Current CLI guidance owns schemas, catalogue controls and limits.

## Changes

- Added `skills/moblend-authoring/SKILL.md` with focused discovery frontmatter, environment discovery, scene/module/shot selection, ownership, diagnostics, preview/repair and verified handoff.
- Added README adoption guidance: copy/link the skill directory into a supported harness location, or read SKILL.md directly; configure the CLI separately.

## Decisions

- Keep the skill transferable as one folder/file; do not duplicate schemas or require the MoBlend source repository alongside an installed CLI.
- Retain independent authoring and compiler-development scopes; report reproducible tool failures rather than mutating the transpiler to satisfy a brief.
- Require honest distinction between validation, compilation, rendering and visual inspection; use in-range preview frames and stop repetitive ineffective repairs.
