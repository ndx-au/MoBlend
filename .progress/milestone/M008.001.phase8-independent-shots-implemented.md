# Phase 8 independent shots implemented

## Summary

Extended project manifests with explicit shot targets. Selected shots resolve only their dependency closure; `--all-shots` validates every shot; outputs nest per shot and record `dependencies.json` hashes. Three-shot example demonstrates change isolation; concurrent Blender previews stay isolated.

## Changes

- Shot selection in loader/CLI (`--shot`, `--all-shots`).
- `dependencies.json` provenance writer.
- `examples/projects/three_shots/` and broken-unselected fixture.
- Phase 8 PLAN/CONTEXT/VERIFICATION; guide shot section.

## Decisions

- Multi-shot projects require explicit `--shot`; sole shot may default.
- Unselected broken modules are not loaded for a selected shot.
- No cache/scheduler/video assembly in this phase.
