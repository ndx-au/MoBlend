# Bound cancellation test observation

## Summary

While qualifying alpha.1, the tag CI succeeded but a parallel branch run and its retry exposed immediate child-state assertions in CLI/probe cancellation tests. SIGKILL is asynchronous across a process group; observing parent exit does not imply every child is terminal in the same scheduling instant. Stabilized the test observations without changing application code, the release tag or uploaded assets.

## Changes

- CLI signal and Doctor descendant tests now poll terminal/missing process state for at most one second and accept the Linux ESRCH exit race.
- A child still live at the deadline remains a test failure; process-tree safety assertions are retained.

## Verification

- 20 repeated CLI/probe test runs: 160 tests/subtests passed across two packages.
- Targeted race suite: 8 passed across two packages.
- Fresh full Go/Blender suite: 134 passed across eight packages; formatting/vet/diff checks clean.
- Rebuilding the CLI with the release flags after this test-only edit produced a byte-identical executable: SHA256 23ce883307962d34929ca8ad4b59012db0271b147bb2aa269a7f8bf4f7006bd0.

## Decisions

- Preserve annotated tag v0.2.0-alpha.1 at 1ccc0038c9e9313ec59a709672fccd3c6669adfa and the verified archive. Apply test-only follow-up on main, disclose source-test timing limitation in release notes.
- Use native gh for CI diagnostics, preserving the owner's no-Node release-path preference over the workflow skill's Node wrapper.

## Follow-ups

- Confirm follow-up CI and finish publishing the already verified draft prerelease.
